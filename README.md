# AS Outfit Studio — Website

Static fashion storefront with WhatsApp order booking (no online payment).

- `index.html` — the whole website (storefront + admin). Your official logo is embedded unchanged.
- `assets/logo-original.png` — copy of your original logo file (backup only).

## Go live with GitHub Pages
1. Create a GitHub repository and upload these files (keep `index.html` in the root).
2. Repository **Settings → Pages → Deploy from a branch → main / (root) → Save**.
3. Your link will be `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

## Edit the website
Open `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/#/admin`, make changes, press **Download index.html**,
then upload it to the repository (replace the old file).

## First things to do
